# Perch

Perch is a free Mac menu-bar app. It catches downloads and screenshots in two small trays, and shaking a file while you drag it opens a ring to convert, rename, copy or send it.

**[Download Perch for Mac](https://github.com/littlemoneymike/perch/releases/latest/download/Perch.dmg)** · macOS 14 Sonoma or later, Apple Silicon and Intel

Website: https://littlemoneymike.github.io/perch/

This repository holds the website and the downloads. Every release is signed with a Developer ID and notarized by Apple.

- [All versions](https://github.com/littlemoneymike/perch/releases)
- [Privacy policy](https://littlemoneymike.github.io/perch/privacy.html): Perch has no accounts and no analytics, and it never connects to the internet.
